
# Tetris

Just another Tetris game written in C and using SDL3.

  <img src="assets/screenshot.png" alt="a screenshot of the tetris" style="max-width: 514px;">
</p>

## Building on Linux

```
git clone https://github.com/nnosyrev/ctetris.git ctetris
cd ctetris
git submodule init
git submodule update
cmake -S . -B build
cmake --build build
```

## Start playing

```
build/tetris
```
